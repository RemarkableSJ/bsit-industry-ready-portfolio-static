# GitHub Pages publishing checklist

1. Keep this static portfolio in its own GitHub repository.
2. Confirm `index.html` is at the repository root.
3. Confirm no secrets, credentials, private data, or personal ID images are committed.
4. Push the `main` branch.
5. Open repository **Settings → Pages**.
6. Select **Deploy from a branch**, branch `main`, folder `/(root)`, and Save.
7. Wait for deployment and open the URL shown in Settings → Pages.
8. Test homepage navigation, project detail pages, dark mode, downloads, and defense presentation.

This is a static website. It has no server-side application or shared database.
