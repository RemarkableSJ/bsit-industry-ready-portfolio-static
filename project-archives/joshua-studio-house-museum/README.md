# Joshua’s Studio House Museum — Static Presentation Demo

A browser-based gallery and storefront presentation built with HTML, CSS, JavaScript, and browser-local storage. It includes artwork/product browsing, collections, filters, variants, cart demonstrations, and simulated commission/checkout flows.

No real orders or payments are processed. Cart and form interactions are presentation simulations only.

## Run locally

Open `index.html` in a modern browser, or run `python -m http.server 8000` from this folder and open `http://localhost:8000`.

## Publish on GitHub Pages

Upload the contents of this folder to a public GitHub repository, then enable Pages from Settings → Pages → Deploy from a branch → main → /(root).
