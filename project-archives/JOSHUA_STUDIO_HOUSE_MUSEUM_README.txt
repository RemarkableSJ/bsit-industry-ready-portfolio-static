Joshua's Studio House Museum — Static Presentation Demo

Use the `joshua-studio-house-museum/` folder for the browser presentation. It includes the gallery, 17 artwork/product images, local product data, browser-local cart, simulated checkout, and simulated commission request form. No Firebase, PHP, PayMongo, PayPal, real order submission, or server-side processing is present in this edition.

To run locally on Windows, open this folder, double-click run_demo_server.bat, and visit http://localhost:8000/.

For GitHub Pages, upload the CONTENTS of `joshua-studio-house-museum/` to a separate repository root. See its README.md and GITHUB_PAGES_DEPLOY.txt.
