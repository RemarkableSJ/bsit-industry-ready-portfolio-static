STATIC SITE · CONTENT MANAGEMENT

How to update this portfolio

This edition has no server-side editor. The published content is maintained in a JSON file in the repository, then rebuilt into the JavaScript file used by the website.

1. Edit the portfolio content

Open data/portfolio.json in a code editor such as VS Code. Update text and links carefully. Keep valid JSON syntax: use double quotation marks, commas between properties, and escape quotation marks inside text.

2. Rebuild the website data file

Install Python 3 if it is not already installed. From the repository root, open PowerShell and run:

python tools/build_portfolio_data.py

This updates assets/js/default-data.js from your JSON source.

3. Preview the website locally

python -m http.server 8000

Open http://localhost:8000 in your browser. Stop the preview by pressing Ctrl + C in PowerShell.

4. Publish your changes

Open GitHub Desktop, review the changed files, enter a commit message, click Commit to main, then click Push origin. GitHub Pages will publish the updated static files.

What this static edition does not provide

  • No private admin login or shared database editor.
  • No server-stored contact messages; contact links open the visitor's email app or social profile.
  • No server-side evidence upload. Add public files to the repository and link them from the portfolio data.
  • Browser-local progress or edits do not change the published website for other visitors.

Security: Never commit API keys, passwords, private student records, local databases, personal identification documents, or confidential workplace information.
